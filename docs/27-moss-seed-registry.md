## 一、能力边界（实测结论）

| 项 | 结论 |
|---|---|
| **综合上限** | **约 8.0-8.4 分**（单跑）；二采 + 选优可到 **8.6-8.8** |
| **商业参考图水平（9+ 分）** | 达不到（MOSS 训练数据/参数规模限制） |
| 人手 / 复杂姿势 | **容易崩**（三条腿、手指糊） |
| 长句 prompt | 能吃（50-150 词效果最好，超过 200 词开始稀释） |
| 非人结构（尾巴/耳） | **必须写成服装道具**（`plush tail attached to the back`），否则崩 |
| 脸部精细描述 | 写太细反而僵；写 `a cute young girl` 更自然 |

## 四、姿势控制（实测有效路径）

| 方案 | 效果 |
|---|---|
| 文字描述姿势（crouches on her heels 等） | ❌ 经常无效（模型理解成坐/站） |
| 负向排除（not sitting） | ❌ 基本无效 |
| **姿势线稿 + img2img（denoise 0.85）** | ✅ **姿势能对上**（但人体结构仍可能崩） |
| 姿势线稿 + img2img（denoise 0.55） | ❌ 直接输出线稿 |
| RS 3D Pose（MOSS 适配器） | ⚠️ 需 BF16 模型 + 313MB 权重，**与风格 LoRA 冲突** |

### 姿势线稿的正确用法

```
1. search_poses 查姿势（如「蹲」→ P061-P066）
2. 下载线稿：https://ai-pose-gallery.anhao.app/img/<view_id>.png
3. img2img：denoise 0.85 + cfg 5 + 鲸鱼娘 LoRA 0.85
4. 负向必须含：lineart, sketch, coloring book, mannequin, doll joints, white background
5. 输出后裁掉白边
```

## 五、二阶段（hires fix）实测

| 阶段 | 参数 |
|---|---|
| 第一段 | 1024×1536 / 40 步 / cfg 4.5 / seed 固定 |
| 放大 | LANCZOS → 1536×2304 |
| 第二段 | denoise 0.4 / 30 步 |

**效果**：+0.2-0.3 分（蕾丝/树皮/发丝细节变清晰）
**代价**：时间 ×2.5（约 3.3 分钟/张）

## 六、稳定出好图的现实做法

```
1. 同 prompt 跑 4 个 seed
2. 挑出最好的一张
3. 记录该 seed（写进本文第二节）
4. 以后固定用这个 seed
```

**不要**指望「一次就出 9 分」——MOSS 的方差很大。

## 七、不要重复踩的坑

| 坑 | 事实 |
|---|---|
| 「写更详细的 prompt 就能到 9 分」 | ❌ 已试，8.4 就是天花板 |
| 「二采能到 9 分」 | ❌ 实测 8.6-8.8 |
| 「RS 3D 姿势能解决姿势问题」 | ⚠️ 要换 BF16 + 丢 LoRA，不划算 |
| 「澜姿 generate_pose_images 能用」 | ❌ 没 API Key，只能取它的文字描述和线稿 |
| 「蹲姿用文字能写出来」 | ❌ 会变成坐 |
