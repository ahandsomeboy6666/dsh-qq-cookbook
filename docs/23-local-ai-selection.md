# 23. 本地 AI 能力选型（生图 / 音频 / 视频）

> **定位**：本仓库**不包含**本地 AI 模型、工作流文件或部署脚本——这些是重资产（几十 GB 下载 + 数小时调试），由使用者在自己的机器上部署。
> 本文只给**技术选型与实测判断**，让后来者少走弯路。

## 0. 为什么不做进仓库

| 项 | 说明 |
|---|---|
| 模型体积 | 单个 5-15GB（生图）、14-30GB（视频） |
| 环境成本 | ROCm/CUDA、ComfyUI 节点、Python 依赖 |
| 硬件绑定 | 同一份配置在不同显卡上不可移植 |

仓库负责**编排层**（QQ 桥接、DSH 会话、工具接线）；模型与推理环境由使用者自建。

## 1. 生图（2026-11 实测）

### 首选：MOSS-Image（8B）

| 项 | 值 |
|---|---|
| 架构 | 8B DiT + Qwen3.5 9B 编码器 + Flux2 VAE |
| 显存 | int8 约 12GB |
| 提示词 | **自然语言英文短句**（不是 Danbooru 标签） |
| 速度 | 1024×1024 / 30 步 ≈ 40-55 秒（9070XT） |
| 质量 | 光影、材质、场景强于同类小模型 |
| 下载 | `Comfy-Org/MOSS-Image`（HF） |

关键配置：CLIP type 选 `moss_image`；`--disable-smart-memory` 让模型常驻（4070Ti/9070XT 实测提速 3-8 倍）。

### 备选

| 模型 | 参数量 | 特点 | 适用 |
|---|---|---|---|
| Anima v1.1 | 2B | Danbooru 标签，动漫 SOTA | 动漫、省显存（5.6GB） |
| Illustrious / NoobAI / Animagine / Kohaku | 2.6B（SDXL） | 老牌动漫，生态大 | 动漫 |
| Qwen Image 2.1 | 20B（int8 ~6.8GB） | 写实强、中文好 | 写实 |
| Krea 2 | 12B | 写实/艺术，8 步 2K | 写实 |

### 分辨率经验

| 尺寸 | 速度（9070XT） | 备注 |
|---|---|---|
| 1024×1024 | 40-55 秒 | 甜点 |
| 1536×2048 | 100-130 秒 | 可用 |
| 1536×2560 | 明显噪点 | 不建议（2B 模型上限） |

> 动漫模型（2B）的分辨率天花板在 1536 左右；要更大靠放大（Real-ESRGAN），不要硬拉。

## 2. 音频（TTS / 唱歌）

### TTS：IndexTTS 2（deployed 在 8080/8090）

| 项 | 值 |
|---|---|
| 用途 | 角色语音（音色克隆） |
| 显存 | ~4GB |
| 实测 | 9070XT 可跑；参考音频 3-10 秒效果最好 |

### 唱歌

| 方案 | 原理 | AMD 支持 | 备注 |
|---|---|---|---|
| SoulX-Singer | 零样本歌声合成（F0/MIDI 控制） | 需改代码（sageattention 跳过、torch 换 ROCm） | 704M 参数，2.7GB |
| RVC | 声音转换（他人演唱转音色） | 社区有一键包 | 需训练/转换 |
| DiffSinger | 直接合成（需训练） | PyTorch 可跑 | 门槛高 |

## 3. 视频

| 方案 | 大小 | 16GB 可行性 | 备注 |
|---|---|---|---|
| LTX-Video | 6GB | ✅ 轻松 | 秒级，质量中 |
| Wan 2.2 14B T2V | 20GB（含编码器） | ⚠️ offload | 质量最高，分钟级 |
| MiniMax H3 | 20B + 32B 编码器 | ⚠️ 需 GGUF Q4/Q6 | 8G/12G 有社区方案 |

MiniMax H3 补充：Comfy-Org 提供 `pruned_w6a8`（14.9GB）等量化版；官方 safetensors 路线对 16GB 不友好，**用社区 GGUF（Q4/Q6）** 更现实；9070XT 有已知 VAE 问题（Comfy-Org issue #17）。

## 4. 硬件参考

| 项 | 本机 |
|---|---|
| GPU | RX 9070XT 16GB（gfx1201，ROCm） |
| CPU | Ryzen 7 9700X |
| 已知问题 | ComfyUI 长跑（20h+）会 ROCm 卡死，需 wmic 杀进程重启；`--disable-smart-memory` 缓解 |

## 5. 结论

- 想在 QQ 里让机器人「会画图/会说话」：装 **ComfyUI + MOSS-Image + IndexTTS 2** 即可，其余是锦上添花
- 视频与唱歌目前仍是**实验性**（速度慢、稳定性差），不建议作为主链路
- 所有模型/工作流请自行下载部署，本仓库不提供二进制资产
