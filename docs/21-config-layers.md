# 配置分层：通用模板 vs 个人配置

> 目的：仓库只放**通用模板**，个人值（QQ 号、群号、端口、音色 ID、预算）只留在本机。

## 一、两个文件

| 文件 | 进 git | 内容 | 谁填 |
|---|---|---|---|
| `config.example.json` | ✅ | 结构 + 占位符（`"<你的QQ号>"`） | 仓库维护者，随功能更新 |
| `config.local.json` | ❌（`.gitignore`） | 真实值 | 部署者，首次部署时生成 |

## 二、什么时候生成 `config.local.json`

**首次部署时**，两种方式任选：

```powershell
# 方式 A：手动生成
node cli.mjs init

# 方式 B：一键启动时自动检测
#   tools/start-feiyu.ps1 检测到缺失会自动从模板复制，并提示填写
```

生成后把 `<...>` 占位符替换成你的值。之后启动脚本优先读 `config.local.json`。

## 三、哪些是个人配置

| 项 | 示例占位符 | 说明 |
|---|---|---|
| QQ 号（owner/私聊白名单） | `<你的QQ号>` | 唯一身份 |
| 群号 | `<群号>` | 可留空 |
| NapCat 目录 | `<你的 NapCat Shell 目录>` | 随安装位置变 |
| 机器人昵称 | `<机器人昵称>` | 唤醒用 |
| 音色 ID（火山/MiniMax 等） | `<你的音色ID>` | 账号内资产 |
| 桌面端端口 | `<桌面端端口>` | 每次重启随机，不要写死 |

## 四、哪些是通用配置（可以进仓库）

- `qq.wsUrl` / `qq.httpUrl`：NapCat 默认 6700/6701
- 人设文件路径（`roles/`）
- 预算档位（30/60/300）——产品设计
- 工具开关（浏览器等）
- 模型/引擎的通用参数

## 五、门禁

`node cli.mjs check` 包含「无个人配置泄漏」检查（`checks/check-privacy.mjs`）：

- 扫描 `config.example.json`、`README.md`、`AGENTS.md`、`BOOTSTRAP.md`、部分文档
- 命中真实 QQ 号（11 位）、随机端口（53800/51047）、音色 ID 模式 → 报红
- 占位符行（含 `<你的`）豁免
- 历史记录（`15-acceptance-record.md` 等）已标注「本机实例」，不扫描

## 六、为什么这样设计

- **安全**：QQ 号、音色 ID 是个人资产，进公开仓库等于泄露
- **可复制**：别人拉下来按模板填自己的值就能跑
- **可追溯**：验收记录保留真实值 + 「本机实例」标注，方便回溯
