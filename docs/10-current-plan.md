# 当前方案（一页纸）

> 状态：**已拍板**（2026-10-27）。这是 agent 开工的唯一入口；与此冲突的旧文档以本文为准。
>
> 决策过程见 [体验评分卡](references/experience-scorecard.md)、[prior art](references/prior-art.md)。

## 一、目标

- **私聊**：肥鱼可爱、活泼、温柔、热情、关心人；能实际关心（点外卖/奶茶）。
- **群聊**：只要好玩（玩梗、表情、斗图），不需要情绪氛围。
- 形式：持久会话 + 主动关心 + 分条，**不是** AstrBot 那种一问一答的 API 对话。

## 二、选型

| 层 | 选择 | 理由 |
|---|---|---|
| 接入 | **cheems135/dsh-qq-bridge**（NapCat 插件） | 聊天体感最好（分条 0.6–2.8s、情绪、记忆、主动），私聊陪伴 5 分；用户拍板 |
| 协议端 | **NapCat**（QQ 小号） | cheems 的原生路线；小号隔离，接受适当封号风险 |
| 能力 | DSH `browser-use`（Playwright MCP）+ `web_search` + 持久登录态 | 刷 B 站/抖音、搜资料、点外卖 |
| 人设 | cheems 面板多套人设（私聊 / 群聊分开） | 改文本即生效，不写代码 |
| 授权 | 小号只加你为好友；只充 30 元余额；受益人只有你和她自己 | 损失上限 = 30 元 |

## 三、架构

```
QQ 小号（只加你为好友，只进群）
  │  OneBot v11（WS + HTTP）
  ▼
NapCat（协议端，扫码登录）
  │
  ▼
cheems135 插件（DSH bundle 内）
  │  session/event + agent.followup
  ▼
DSH agent（人格卡 + 工具）
  ├─ browser-use（Playwright MCP）→ B 站 / 抖音 / 美团 / 拼多多
  ├─ web_search / web_fetch → 搜资料
  └─ 记忆 / 情绪 / 表情包 / 语音
```

## 四、两套人设

| 场景 | 人设 | 关键词 |
|---|---|---|
| 私聊（只有你） | 活泼、热情、可爱、温柔、关心 | 短句、主动问候、难过时先安慰再提议点奶茶 |
| 群聊（公开） | 好玩、会玩梗、斗图 | 被 @ 才接、短、有梗、不刷屏 |

人设写在 cheems 面板的「角色与互动 → 人设」里，按联系人/群分别指定。改完保存，`presetRev +1` 新会话生效。

## 五、零花钱授权（三维闸）

| 入口 | 受益人 | 结果 |
|---|---|---|
| 私聊（只有你） | 你（锁定地址） | ✅ 可买 |
| 私聊（只有你） | 肥鱼自己（小号账号） | ✅ 可买 |
| 私聊（只有你） | 其他人 | ❌ 拒绝 |
| 群聊（任何人） | 任何人 | ❌ 不开放购物 |
| 任何入口 | 转账 / 红包 / 代付 | ❌ 永远拒绝 |

- 小号只充余额、不绑主号银行卡；优先小额免密，密码只给小号。
- 每笔记账（时间/商品/金额/受益人），花完提醒。
- 单日笔数上限（默认 5 笔），防刷单。

## 六、代价与风险（知情）

| 风险 | 影响 | 处理 |
|---|---|---|
| NapCat 封号 | 小号没了 | 小号隔离、控制频率、不发垃圾消息 |
| 功能重（18 页面板、多模块） | 学习成本 | 只用「人设 / 连接 / 素材 / 记忆」四页 |
| 文字审批（无按钮） | 支付确认要打字 | 小额免密覆盖；大额人工 |
| Windows 向功能（SAPI、隐藏启动） | 跨平台受限 | 本机 Windows，可用 |
| browser-use 是实验性提供方 | 可能不稳定 | 先验证 B 站，再碰抖音/美团 |

## 八、下一步

1. 装 NapCat + 扫码登录（人做）。
2. 装 cheems 插件，填 wsUrl/token，重启 DSH（agent 可做大部分）。
3. 写私聊/群聊两套人设（agent 起草，人改）。
4. 验证 browser-use，试刷 B 站。
5. 小额测试：让你说「点杯奶茶」，跑到支付页停住。

## 九、不做什么

- 不做 AstrBot 式无状态问答。
- 不自建桥接（cookbook 只留作验收资产）。
- 不给主号支付密码、不绑主号银行卡。
- 群聊不开放购物/本地文件/浏览器。
- 不追求「群聊情绪氛围」（用户明确说不需要）。
